# CASA GROOVE

Una experiencia de interiores retro para explorar a tu ritmo. Proyecto de portafolio de [Chriss-DW](https://github.com/Chriss-DW).

Esta base integra una entrada al atardecer, seis fotografías de inspiración con vistas ilustrativas, música ambiental original y una sala 3D personalizable. HTML, CSS y JavaScript con Three.js y Web Audio.

Los archivos de la página están en `dist/`; se ejecutan con un servidor HTTP. Las imágenes y dependencias conservan sus créditos y licencias en `docs/ASSETS.md` y `dist/assets/`. La portada es una imagen conceptual generada con IA.
