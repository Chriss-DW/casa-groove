# CASA GROOVE

Este repositorio es el lugar para continuar la evolución de CASA GROOVE. El usuario pidió conservar avances mediante commits y seguir trabajando con GitHub.

- Conservar la estética retro cálida y el carácter de exploración sin presión comercial.
- Editar el contenido en scripts/catalog-content.mjs y regenerar con node scripts/build-catalog.mjs cuando corresponda.
- Ejecutar node --test scripts/selection.test.mjs y node scripts/check-site.mjs antes de confirmar cambios; comprobar escritorio y móvil para interfaces.
- Agrupar mejoras relacionadas en commits con mensajes concretos; mantener fechas reales y evitar commits vacíos.
- Usar ramas codex/ para nuevas tareas y el flujo descrito en CONTRIBUTING.md.
- Mantener la selección local y las fotografías independientes del éxito de WebGL.
- Conservar créditos, licencias y distinción entre fotografía, portada conceptual y modelos ilustrativos.
- No publicar metadatos del alojamiento, credenciales ni archivos locales de revisión.
