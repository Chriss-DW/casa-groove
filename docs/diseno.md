# Dirección de diseño

CASA GROOVE propone una exploración tranquila de interiores retro. El fondo nogal oscuro, los textos crema y el latón conectan catálogo, música y sala. Bodoni Moda organiza los títulos, Inter sostiene la lectura y Shrikhand queda para la marca.

Las fotografías dominan el catálogo; las vistas 3D se identifican como ilustrativas. Tres recorridos sugieren afinidades y cada pareja recomendada tiene un motivo propio. La cesta se llama Mi selección: conserva ideas, no expresa una compra.

La interfaz mantiene foco visible, controles HTML, objetivos de interacción amplios y reducción de movimiento. Los diálogos conservan el botón de origen durante la navegación entre catálogo, selección y detalle. La lectura y el guardado no dependen de que WebGL pueda arrancar.
